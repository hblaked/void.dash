Connect a server

Your worlds, your hardware. Choose how void.dash connects.

PROCESS SETTINGS

Use an existing server directory. Install Java and your server jar, and accept Minecraft’s EULA yourself before starting.

RCON CONNECTION · OPTIONAL FOR LOCAL SERVERS

Enable RCON in server.properties for command discovery and full player lists. Use it only on trusted networks or a VPN; RCON is unencrypted.

REMOTE AGENT

The same Rust executable runs on the server host. Open the connection guide for setup. A remote agent provides logs, metrics, and process controls.

ANOTHER PERSPECTIVE

Add a plugin viewer

Connect a web interface provided by a plugin running on your server.

The plugin must be installed and its website reachable from your browser. Some plugins block embedding; you can always open them in a new tab.

A QUICK FIELD GUIDE

Meet your control room.

void.dash runs entirely from one Rust executable. The dashboard stays on this computer; your Minecraft servers can live anywhere on your trusted network.

01 / Local servers

Add an existing Minecraft server directory, Java executable, and launch arguments. Start it here to stream stdout/stderr, send commands, and manage its process. Host metrics describe this computer; process memory is the Java process’s resident memory, not JVM heap.

02 / Network servers with RCON

Set enable-rcon=true, rcon.port=25575, and a strong rcon.password in the server’s server.properties. RCON supports commands and stopping. Full logs, host resources, starting, and restarting require an agent. Keep RCON on a trusted LAN or VPN.

03 / A remote agent

Copy the Rust binary to your server host, configure a local server there (see README), and set VOID_DASH_TOKEN to a unique token of at least 32 characters. Run: 

void-dash --agent --bind 0.0.0.0 \
  --config /path/to/config.json

Add that agent’s URL, token, and configured server ID here. Restrict agent access to trusted machines; use a VPN or HTTPS reverse proxy across untrusted networks. Tokens remain in your local configuration and never enter the page.

04 / Commands & players

Click “Discover commands” after the server starts. Suggestions come from the server’s help output, including plugin commands when exposed by its help system. RCON help is paged; console help may expose fewer commands. Minecraft status can return a player sample; RCON or console list supplies the full list. Skin faces load from mc-heads.net with a local fallback.

05 / Plugin viewers

Install squaremap, BlueMap, Dynmap, Plan, or another web plugin on your Minecraft server, then add its reachable website URL. void.dash embeds the site or opens it in your browser; it does not install plugins or create their maps.

Stop managed servers before closing void.dash to preserve console control. Closing the dashboard does not automatically stop your worlds.
